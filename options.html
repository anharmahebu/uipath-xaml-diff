A GitHub token is required for private repositories. Public repositories work without one, but are limited to 60 requests/hour.

Create a fine-grained personal access token (GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens):
Repository access: only the repositories you review.
Permissions: Contents: Read-only and Pull requests: Read-only.

The token is stored only in this browser (chrome.storage.local) and is sent only to api.github.com.
